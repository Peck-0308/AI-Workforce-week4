# Steps Taken – Use Case 1

## Step 1
I logged into Microsoft Copilot using the test account that was provided for the assignment.

## Step 2
On the left side menu, I clicked on “New Agent” to create a new Copilot agent.

## Step 3
I entered a description explaining the type of agent I wanted to create. The description was focused on helping Exchange administrators with simple support tasks like mailbox management, distribution groups, Exchange Admin Center access, and mail flow guidance.

Prompt used:

```text
Create a lightweight IT support assistant for Exchange administrators. The agent should provide short and clear guidance on accessing the Exchange Admin Center, managing user mailboxes, managing distribution groups, and basic mail flow troubleshooting. Responses should be concise, beginner-friendly, and focused only on Microsoft Exchange administration tasks.
```

## Step 4
After entering the prompt, Copilot automatically generated the agent for me. The agent name created was “Exchange Support Assistant”.

## Step 5
I reviewed the generated instructions and settings created by the system.

## Step 6
I tested the agent using different prompts to see how well it would respond.

The prompts I tested were:

How do I access the Exchange Admin Center?

How can I manage a user mailbox in Exchange?

How do I create or manage a distribution group?


What should I check if mail flow is not working properly?


## Step 7
I observed the responses given by the agent and took screenshots during the process.
